
# To-Do List Application

## Project Information

- Project Name: To-Do List Application
- Subject: Object-Oriented Programming
- Language: Java
- GUI Framework: Java Swing

## Description

The To-Do List Application is a desktop-based
task management system developed using Java Swing.

It allows users to add, delete, complete and
organize their daily tasks through a graphical
user interface.

## Features

1. Add new tasks.
2. Mark tasks as completed.
3. Delete selected tasks.
4. Clear all completed tasks.
5. Filter pending and completed tasks.
6. Display task statistics.

## Technologies Used

- Java
- Java Swing
- AWT
- Event Handling
- Layout Managers

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Methods
- Constructors
- Inheritance (JFrame)
- Method Overriding

## How to Run

1. Install JDK 17 or later.
2. Open the project in IntelliJ IDEA.
3. Create the Java class ToDoListApp.
4. Paste the source code.
5. Run the main() method.

## Conclusion

This project demonstrates the practical
implementation of Java GUI programming,
event handling and object-oriented concepts.
